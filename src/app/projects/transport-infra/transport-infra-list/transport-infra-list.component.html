Dialog with elements

Header Section

"Construction Provision | Detailed Project Report" This is the main title/navigation header. It shows the module you are working in (Construction Provision). The tab selected is Detailed Project Report.

Filters & Search Area

This section allows you to filter or search projects. It includes: Sub Company (Dropdown) → Lets you filter projects by sub-company. Select Project (Dropdown) → Lets you choose a specific project from a list. Project Code or Name (Search Box) → A text field to search directly by entering project code or name. Refresh Button (Blue circular arrow) → Refreshes/reloads the project list.

Action Buttons

On the right-hand side: Upload Button (⬆️) → Possibly for uploading data/files related to a project. +Project Button → Used to add a new project into the system. Download Button (⬇️) → Allows exporting or downloading project details (Excel, PDF, etc.)..

Project List Table

This is the main data grid displaying projects. It has columns: Sr. No. → Auto-generated serial number. Project Code → Unique identifier for the project. Project Name → Name of the project. Location → Project location. Client Name → The client associated with the project. Concern Person (Dropdown/Expand Icon) → Likely shows contact details or responsible person when expanded.

Pagination Section (Bottom)

Items per page: 3 → Shows 3 projects per page. 1 – 3 of 3 → Displays current record range. Pagination Controls (⏮ ⬅ ➡ ⏭) → Navigate between pages when more data exists.
